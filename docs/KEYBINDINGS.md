## 输入行（composer）

`i` 或 `/` 进入（:2659）：可见字符打字、退格删字符、回车提交（:2521）、Esc 取消（:2550）。
提交去向按所在面分发：Agent 台给 composer，终端面经 `POST /__term` 跑只读白名单命令，
文件面按路径 `ls`/读代码，别的面如实说「这一面没有输入行」。

## 终端面只读白名单

终端面（第 11 面）输入行只接受服务端白名单内的命令，白名单实测
（`python3 tools/agentos.py term '__agentos_list_probe__'`，rc=1 报错里带回）：

```text
cat date find git grep head ls pwd python3 stat tail wc whoami
```

白名单不在本地抄一份：TUI 每次向服务端 `/__term` 现取
（`tools/agentos.py:1643` `def allowlist`），命令找不到就整个不上表，屏上不会列出一条跑不了的命令。

## 数字键的两条硬规矩

1. 判据是 ASCII 数字表 `("1".."9","0")` 而不是 `key.isdigit()`：`isdigit()` 认全角「１」和上标「²」，
   `int("²")` 直接抛 `ValueError`，结果是「敲了一个上标字符，TUI 崩了」（:2680-2690 注释）。
2. `0` 单独映射第 10 面：`int("0")-1 = -1` 在 Python 里是合法下标（末面），
   照抄公式会把第 10 面静默跳到第 13 面（:2681-2683 注释）。
